# Frontend

One web app for the integrated system, with a page per component. It talks only to the
backend API, never directly to the models.

| Page | Component | Shows |
|------|-----------|-------|
| Risk assessment | C1 | child risk/status prediction |
| Recommendations | C2 | feasible intervention suggestions |
| Model health | C3 | shift flags, maintenance decision, model version history |
| Forecast | C4 | area-level burden and resource demand |

_Framework not chosen yet. Add setup and run instructions here once it is._
